# パリの街を広げる

![セーヌ川の橋と2つの市街地](screenshots/paris-diorama.png)

2026-10-12。ワールドを256×256から384×384へ広げ、エッフェル塔の西側にあった街並みに加え、東側に新しい市街地を作った。フランス風の建物は合計163棟。二つの街をセーヌ川風の運河と石橋2本でつなぎ、凱旋門、回転木馬、カフェ席、小舟を配置した。メニューの「パリの全景とセーヌを見渡す」から街全体へ移動できる。

建物は明るい石壁、色違いの屋根、窓、煙突、屋根窓、バルコニー、店先のひさしを組み合わせた独自モデル。エッフェル塔と凱旋門は街並みの中で見つけやすい高さに調整した。建物、橋、記念物は従来の地形データにも残るので、旧ボクセル表示と住民の移動・当たり判定を保つ。三次元モデルは地形編集とは別の表示レイヤーに置いた。

表示負荷を抑えるため、街のモデルを4つの128×128区域へまとめ、地形は32×32の144チャンクで描く。地形メッシュは近い区域から表示し、遠い区域はWeb Workerで後から読み込む。保存バージョン7から8への移行では、村・住民・時計・橋・編集差分を保つ。更新前の実データは `backups/phase7-before.sqlite` にバックアップした。

更新前の保存データはseed73129、revision343、編集733件、住民20人。追加した街の固定ブロックと既存編集の重なりはなく、元の拠点からエッフェル塔まで257セル、凱旋門まで368セルの経路を確認した。Docker Composeは両サービスとも正常起動し、バックエンドはhealthy。

内蔵 AMD Radeon Graphics、1280×720、パリ全景で10秒間測定した結果は、高品質で平均59.9 FPS、フレーム95%値17.7 ms、CPU描画13.1 ms、1,243描画呼び出しだった。高品質のままPCの60 FPS目標にほぼ届いた。自動品質は負荷に合わせて設定を下げ、60 FPS前後で動作した。iPhone Safari実機の30 FPS目標は未測定。

主な変更は `shared/world.ts`、`backend/src/database/store.ts`、`frontend/src/renderer/`。確認では `npm run build` とDocker起動を実施した。都市モデルのジオラマ表示と旧ボクセル表示の切り替え、旧保存データの移行と編集復元を維持する。
