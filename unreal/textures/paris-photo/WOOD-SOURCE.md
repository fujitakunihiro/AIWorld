# Door wood appearance source

- Asset: [Dark Wood](https://polyhaven.com/a/dark_wood), Poly Haven.
- Authors: Dimitrios Savva (photography), Dario Barresi (baking), Rico Cilliers (tiling).
- License: [CC0](https://polyhaven.com/license). The asset maps, not the website's example render, are bundled.
- Source width: 2 metres, 2048×2048 originals. `manifest.json` records original URLs, byte sizes, provider MD5 and SHA-256 for all three files.
- Imported channels: diffuse sRGB; DirectX normal linear; ORM linear (R=AO, G=roughness, B=metallic). No height or metal channel is interpreted as displacement.
- Modification in UE: vertical grain in the existing cathedral frame; reduced normal strength; outdoor roughness floor; mild estimated patina/tint. Mesh boards and forged iron remain separate three-dimensional surfaces.
- This is a wood appearance proxy, not timber sampled at Notre-Dame. The source describes a dark hardwood appearance; no claim is made about the cathedral's actual timber species.

The [cathedral's Sainte-Anne description](https://www.notredamedeparis.fr/comprendre/architecture/portail-sainte-anne/) documents the forged door hinges. The generated branching patterns are original inferred ornament, not a measured reproduction or a copy of a photograph. The GIS anchor, original footprint and collision stay unchanged.
