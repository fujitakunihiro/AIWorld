# AI WORLD / パリ散策 操作ガイド

## まず覚える操作

1. **H** を押すと、ゲーム内に日本語の操作ヘルプと追加ボタンが表示されます。もう一度 **H** で閉じます。
2. 画面上部のボタンは左クリックでも使えます。ボタンに表示されているキーを押しても同じ操作です。
3. **右ボタンを押したままマウスを動かす**と視点が回転します。右ボタンを離すとカーソルが戻ります。
4. **WASD** で移動し、マウスホイールでズームします。
5. HUD全体を消したときは **F10** をもう一度押すと戻ります。

## 移動と視点

| キー・操作 | 内容 |
|---|---|
| 右ボタンを押しながらマウス移動 | カメラを回転。右ボタンを離すとカーソルを表示 |
| WASD | 俯瞰・自由カメラの移動、または主人公の歩行 |
| Shiftを押しながらWASD | 主人公が走る |
| 矢印キー | カメラの向きを調整 |
| マウスホイール | 俯瞰のズーム、または三人称カメラの距離調整 |
| F2 / Overview | 全景に戻る。主人公操作中は俯瞰カメラに戻る |
| F3 / Fly | 地上目線の自由カメラに切り替える |
| F8 / Explore | 主人公を出して三人称で散策。主人公操作中は一人称・三人称を切り替える |
| V / View | 一人称・三人称を切り替える。俯瞰中なら主人公で散策を開始 |

## キーボードだけで使う機能

| キー | 内容 |
|---|---|
| F1 | 建物の再現レベルなどの診断表示を切り替える |
| C | 近くの車に注目し、車両情報を表示する |
| I | スーパーへ注目する |
| Y | レストランへ注目する |
| Z | 花屋へ注目する |
| X | パン屋へ注目する |
| Q | 本屋へ注目する |
| J | サント・シャペル専用視点を開く・閉じる |
| O | 旧司法宮の窓の専用視点を開く・閉じる |
| U | セーヌ川のクルーズ船を追従する・通常視点へ戻る |
| K | 最寄りの駅へ入る、または地上へ出る |
| L | 停車中の列車に乗る、または到着後にホームへ降りる |
| N | 歩行者の経路表示を切り替える |
| 4 / 5 / 6 | 固定の写真撮影用カメラに切り替える |
| F9 | `unreal/AIWorld/Saved/Screenshots/paris-twin.png` に画面を保存（同名ファイルは上書き） |

メトロは **Kで駅に入る → Lで乗車 → 到着まで待つ → Lで降車 → Kで地上へ出る** の順です。走行中は降車できません。

## 画面の色が変わったとき

**F1・F4・F5** は調査用の表示です。建物の色分けや輪郭だけの表示になっても、通常表示が壊れたわけではありません。**F2** を押すと診断表示を解除して全景へ戻れます。

## HUDを隠したとき

**F10** はボタン、操作案内、下部のステータスをまとめて隠します。再表示も **F10** です。HUDを隠している間はHヘルプも見えないので、F10でHUDを戻してからHを押してください。
