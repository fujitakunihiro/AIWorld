# パリのワールド再構成

384×384の島々を、セーヌ川と市街地がつながるパリのワールドへ作り直した。マップ座標上では川を南北に流し、実際の位置関係に合わせてエッフェル塔を西南、凱旋門を西北、ルーヴル美術館を東側、ノートルダム大聖堂をシテ島へ配置した。市街地の間を石橋6本で結び、凱旋門から放射状に伸びる大通りと街区を設けた。

地形は川岸と公園を除いて平坦な石畳の都市面にし、ハウスマン様式の建物558棟を配置する。シテ島、エッフェル塔のシャン・ド・マルス、ルーヴル周辺には広場・公園を残した。ルーヴルの中庭とガラスのピラミッド、ノートルダムの双塔・身廊・尖塔屋根は独自のThree.jsモデルで追加した。島の輪郭や以前の記念物の座標には依存しない。

住民AI、資源、建築、時刻は同じシミュレーションを使う。ゲーム内地形では街区・橋・塔の輪郭を維持し、ジオラマ表示では建築モデルを重ねる。都市の静的メッシュは192×192の4地区にまとめ、描画呼び出しを104グループに抑えた。UE向けのネイティブモデルは既存の `tools/export-unreal.ts` から再出力され、パリ表示のカメラもワールド中央へ合わせる。

保存バージョン9への移行では住民、村の建物、資源、進行時刻、プレイヤーの地形編集を保持し、新しい都市地形へ読み替える。移行イベントを村の歴史に記録する。

## 確認

- `npm run typecheck` と `npm run build` に成功。
- 384×384の地形生成、主要地点の歩行可能性、6本の橋による両岸の接続、街区の重なり防止、4地区のメッシュ結合、保存移行をテスト。
- 自律行動の1000ステップ試験を通過。長時間の住民・住宅・農業シナリオも通過。
- 現行のグラフィック品質・性能はブラウザーとUE実機で未計測。高解像度のパリ空撮は別途コンセプト画像として生成済みで、実ゲームは操作・衝突判定のためボクセル地形と描画モデルを維持する。
