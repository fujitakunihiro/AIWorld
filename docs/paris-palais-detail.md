# Palais de Justice: window detail near Sainte-Chapelle

The nearest large building in the current GIS dataset is `osm/relation/536982`, the Palais de Justice de Paris. The palace surrounds the chapel, as described by the [Cour d’appel de Paris](https://www.cours-appel.justice.fr/paris/bonne-visite). The original OSM footprint, IGN height enrichment, collision, roof and building selection remain unchanged. Within 50 m of the chapel, the layer adds depth to **790 existing inferred window quads**: stone surrounds, sills, head mouldings, wooden frames, glass and small iron handles. The original balcony railings remain in place.

This is an inferred exterior study, not a surveyed or photogrammetric reconstruction. The window quads, joinery, handles and repeated detailing are estimates; the windows are decorative surfaces on the original solid walls, with no actual interiors. The work does not reproduce all parts of the palace or assert that each window matches its real counterpart. Existing photo-derived stone/wood materials and project glass/iron materials are reused. OSM data © OpenStreetMap contributors, ODbL.

The reproducible source `unreal/AIWorld/Content/Data/paris-palais-frontages.json` records the GIS scene hash and each original source mesh, quad index, centre, normal, and distance from the mapped boundary. The generator assigns each window to the nearest source polygon, rejects placements inside adjacent buildings, and chooses an inspection position outside mapped buildings. The runtime uses four shared instanced meshes, has no collision, and refuses to load the layer against a different GIS source hash. Low quality and footprint/issue/accuracy displays hide the added layer and show the original GIS.

Run `Paris-Palais.cmd` or `unreal/scripts/Start-ParisDigitalTwin.ps1 -PalaisView -Quality Medium`. O toggles the close inspection view; J shows the chapel and F2 returns to overview. `gis/.venv/Scripts/python.exe unreal/scripts/generate_paris_palais_frontages.py` regenerates the layer from existing offline GIS data. `gis/.venv/Scripts/python.exe unreal/scripts/tests/test_paris_palais.py` tests original quad traceability, source-boundary alignment, camera clearance and reproducibility. `unreal/scripts/Test-ParisDigitalTwin.ps1 -Photoreal` includes the PalaisFrontages Unreal automation test.

For a controlled before/after comparison, use `unreal/scripts/Measure-ParisDigitalTwin.ps1 -View Overview -Photoreal -PalaisView -Quality Medium -Duration 10 -CaptureAfter 10 -CleanFrame`; add `-NoPalaisDetail` for the original appearance. The measurement uses the same camera in both cases and the current graphics hardware, not a hardware-independent performance guarantee.

Measured on the local PC in a 1280×720 window at Medium (80% internal screen percentage), D3D12/SM6, after asset preparation: the 10-second comparison recorded 42.3 FPS without and 42.1 FPS with the layer (P95 27.0 ms vs 26.6 ms). These short runs have variability and are not a guarantee on other hardware. The final shared prototypes have 96 stone, 72 wood, 2 glass and 72 iron triangles, instanced rather than duplicated as individual actors.

## Reflective window study and real-world reference

The Palais inspection camera uses a modest exposure compensation for the shaded courtyard. The original solid GIS walls remain unchanged. A separately built material `M_PalaisReflectiveGlass` adds reflective PBR glass and a view-dependent **procedural room illusion** with deterministic per-window variation. The rooms and curtains are artistic approximations, not actual photographed or modeled interiors. The glass is opaque and cannot be entered. An explicit `-NoPalaisPhotoGlass` measurement flag restores the earlier glass for a comparison with the same camera and exposure. The material can be reproduced via `unreal/scripts/Build-ParisPalaisGlass.ps1`; it copies the existing project material and enables instanced rendering without modifying it.

A [Panoramax 360° photo near the current Palais view](https://api.panoramax.xyz/#focus=pic&pic=cc263a92-e5e2-468e-9dfa-fb5fe41c14a8), by overflorian, CC BY-SA 4.0, was taken on 2025-10-25 about 13 m from the current target. Its location accuracy is reported as 4 m. It is a useful reference, but the specific wall and camera registration have not been independently verified; the photo is **not** projected into the project and does not imply a scanned reconstruction. Its metadata is recorded in `docs/paris-palais-photo-reference.json`. The image shows architectural richness and window/ground-floor structures that the current regular window array does not yet establish; comparison is observational, not a measurement of individual dimensions.

Photo-level parity is not achieved. It would require properly registered multi-view photographs or licensed photogrammetry of the same facade, actual window and floor layouts, door and ornament geometry, and calibrated materials and lighting; substitute or mismatched photography cannot establish those facts.

Validation on the current AMD Radeon(TM) Graphics PC, UE 5.8.3, D3D12: all 31 Unreal automation tests and the 3 Palais geometry tests passed. With the reflective glass enabled at the same inspection view, a 10-second run measured 40.5 FPS at 1280×720 Medium (80% internal resolution) and 22.2 FPS at 1920×1080 High (100% internal resolution). The 60 FPS target was not reached in these short measurements; results vary with scene and shader warmup. Reports: `docs/paris-palais-glass-after-performance.json` and `docs/paris-palais-glass-high-performance.json`.
