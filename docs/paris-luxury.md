# 花と装飾を加えた街角

既存の店舗に縞模様と波形の裾を持つひさし、真鍮風の縁取り、彫刻風の石の飾り鉢と花を追加する。既存のカフェテーブルには大理石風の天板、カップ、小さな卓上花、椅子のクッションを重ねる。店舗や建物の位置は保存済みの OSM に基づく。ひさし、鉢、食器などの位置・外観は創作による推定であり、現在の店舗の実物を再現したものではない。

近接する 80 店舗のひさし、既存の 49 組のカフェテーブル、検査を通過した 64 基の飾り鉢を対象とする。新しいテーブル席は作らず、元データに `outdoor_seating=yes` があり、既存生成処理が配置した席だけを飾る。

鉢の接地範囲が歩行面に 98% 以上入り、外側の歩行空間にも十分な歩行面があることを検査する。元建物・河川・車道・橋、既存の街路設備、店舗の入口への通路、歩行者の既存経路と接地部分が干渉する候補は除外する。高さは実行用シーンの歩行面の三角形から補間し、元店舗の床と大きく高さが異なる候補も採用しない。

生成結果は `unreal/AIWorld/Content/Data/paris-luxury.json` に保存する。元店舗と建物の ID、元 POI 座標、推定した鉢の座標、歩行面の被覆率、配置を見送った理由、モデルのハッシュを追跡できる。鉢をクリックすると親店舗の ID と推定配置の緯度経度を表示する。F6 で街路設備を隠すと、鉢の当たり判定も消える。

現在は上階の装飾を含む 28 種の共有メッシュをインスタンス表示し、品質設定と距離に応じて描画する。花や小さな葉、細い電飾には動的な影を付けず、追加の点光源は作らない。

起動は `Paris-Luxury.cmd`。PowerShell からは `./unreal/scripts/Start-ParisDigitalTwin.ps1 -LuxuryView`。再生成は `./unreal/scripts/Build-ParisLuxury.ps1`、確認は `./unreal/scripts/Test-ParisLuxury.ps1`。保存済みの GIS データからオフライン生成でき、同じ入力の再生成結果を検査する。実行時に元シーンのハッシュが一致しない場合は追加装飾を表示しない。

第1段階の検証では C++ ビルド、Python 4 テスト、UE 6 テストが成功した。結果は [検証記録](paris-luxury-validation.json) に保存する。[変更前](paris-luxury-before.png)、[変更後](paris-luxury-after.png)、[雨の夜](paris-luxury-night.png)を同じ視点で自動撮影する処理は `Capture-ParisLuxury.ps1 -View Before|After|Night`。実測値は各画面に対応する `paris-luxury-*-performance.json` に保存する。

第1段階の 1280×720、Medium、画面倍率 80%、DX12 の同一カメラでの短時間計測は、昼の変更前が約 33.6 fps、変更後が約 32.7 fps、雨の夜の変更後が約 31.2 fps。昼のフレーム時間の 95 パーセンタイルは約 32.7ms → 33.9ms。限られた視点での参考値で、街全体の性能を保証するものではない。暫定目標の 60 fps は未達。

花と電飾を増やした第2段階 `paris_floral_illumination_v2` では、鉢の花をピンク・赤・紫を含む配色に変更し、78 店舗に吊り花 156 個と花の帯を追加する。80 店舗には 12 球ずつ、計 960 球の暖色の電球列を配置する。吊り花はひさしの前側に置き、花は通りから見える方向を向ける。歩行面や頭上に余裕のない 2 店舗では吊り花を採用しない。元シーンの歩行面を複数点で補間し、最も低い部分の下に 205cm 以上の空間があり、吊り花の下が車道や水面と重ならない場合だけ採用する。

電球は既存の `MPC_ParisNight.NightAmount` と連動し、昼は発光を止め、夜は暖色に光る。配置や装飾はすべて既存店舗を基準とする推定で、現地の花や電飾を記録したものではない。元店舗 ID、見送り理由、地面からの最小高さを同じ JSON に保存する。

第2段階の確認は [昼の実画面](paris-blossoms-after.png)、[雨の夜](paris-blossoms-night.png)、[前段階の同じ視点](paris-blossoms-previous.png)。撮影は `Capture-ParisLuxury.ps1 -View After -OutputPrefix paris-blossoms` と `-View Night` で再実行できる。起動は従来どおり `Paris-Luxury.cmd`。

第2段階では花弁を丸くし、花の向きと大きさにばらつきを加え、葉や花弁に薄い素材の透過光を設定する。花を通り側から見える向きにし、吊り花はひさしの前に出す。C++ ビルド、Python 5 テスト、UE 6 テストが成功し、[検証結果](paris-blossoms-validation.json) に記録する。最終の同一視点での参考値は、1280×720・Medium・画面倍率 80% で昼約 30.0 fps、雨の夜約 28.9 fps。暫定目標の 60 fps は未達。

第3段階 `paris_facade_gardens_v3` では、122 か所の上階の窓辺、14 か所の布飾りと壁灯を追加し、起動時の視点を上階まで見える位置へ広げる。[詳細と検証手順](paris-facade-gardens.md)
